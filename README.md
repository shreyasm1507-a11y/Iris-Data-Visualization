# Iris-Data-Visualization
Objective: Visualize patterns and compare features in the Iris dataset.

Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn, VS Code.

Methodology

*Loaded the Iris dataset using Scikit-learn.

*Inspected the dataset and its features.

*Created a bar chart comparing average petal length by species.

*Created a histogram showing the distribution of sepal length.

*Created a scatter plot comparing petal length and petal width.

*Compared measurements across Setosa, Versicolor, and Virginica.

Key Findings

Setosa generally has shorter petals than the other two species.

Petal length and petal width help distinguish the three species.

The histogram shows how sepal length is distributed across the dataset.
